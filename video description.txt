Chrome Prompt API Demo — Draw & Describe with Gemini Nano (On-Device AI)

Try it live: https://matmercer.github.io/prompt-api-demo/
Source: https://github.com/MatMercer/prompt-api-demo

Chrome now ships an on-device AI model — Gemini Nano — accessible from any web page via the built-in Prompt API (window.LanguageModel). No server, no API key, no network round-trip. In this demo I draw on a canvas (or upload an image), and the browser describes what it sees, fully client-side.

What's shown:
• Multimodal input: sending a canvas bitmap as an `image` content part
• LanguageModel.create() with expectedInputs / expectedOutputs
• Streaming responses via promptStreaming()
• System prompts, assistant prefix, temperature, topK
• Structured output with responseConstraint (JSON Schema)
• Live debug log: download progress, token usage, context window, TTFB

Requirements: Chrome 148+ desktop, GPU with more than 4 GB VRAM, ~22 GB free disk for the model download. Enable these flags:
• chrome://flags/#optimization-guide-on-device-model
• chrome://flags/#prompt-api-for-gemini-nano-multimodal-input

Useful links:
• Prompt API docs: https://developer.chrome.com/docs/ai/prompt-api
• Built-in AI overview: https://developer.chrome.com/docs/ai/built-in
